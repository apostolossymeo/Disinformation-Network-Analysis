# Data Directory

Place the following files here before running `analysis.py`:

- `tweets.csv` — IRA tweet records (~203,000 rows)
- `users.csv`  — IRA account metadata (~454 rows)

**Source**: [Kaggle — Russian Troll Tweets](https://www.kaggle.com/datasets/vikasg/russian-troll-tweets)

Originally sourced from NBC News and compiled by researchers at Clemson University
(Linvill & Warren). This dataset is a subset of the larger FiveThirtyEight IRA dataset.

These files are excluded from the repository to comply with data redistribution norms.
